# Остров Шторма — Godot 4.3

3D-королевская битва для Android на движке Godot 4.3 (рендерер Compatibility, работает на большинстве телефонов с OpenGL ES 3.0).

**Готовый APK:** `release/storm-isle.apk`. Скачай на телефон и установи; Android попросит разрешить установку из этого источника.

## Что в игре
- 20 бойцов: ты и 19 ботов. Дирижабль, свободное падение, парашют.
- Плавная графика без кубов: персонажи из капсул и сфер, сглаженный рельеф с шейдером детализации, пушистые кроны, деформированные шумом камни, качающаяся трава, вода с волнами и бирюзовой лагуной, процедурное небо с солнцем, мягкие тени, глубинный туман.
- 6 локаций: Рыбацкая бухта, Старый форт, Нефтебаза, Солнечные холмы, Маяк, Центр.
- 5 видов оружия четырёх редкостей, гранаты (физика RigidBody), аптечки, броня.
- Способности: рывок и лечащий купол (снаружи пули не проходят, изнутри — можно стрелять).
- Прыжковые платформы с планированием, сужающийся шторм в 5 фаз, аирдропы.
- Все звуки и музыка синтезируются кодом при запуске.
- Сенсорное управление с мультитачем: джойстик, обзор, стрельба с прицеливанием на ходу, помощь в прицеливании.

## Структура
| Файл | Что делает |
|---|---|
| `scripts/game.gd` | Матч, ИИ ботов, камера, управление, шторм, лут, аирдропы |
| `scripts/world.gd` | Процедурный остров: рельеф, города, природа, вода, небо, мини-карта |
| `scripts/fighter.gd` | Боец: модель, анимация, движение, стрельба, способности |
| `scripts/hud.gd` | Меню, HUD, мультитач-кнопки, мини-карта, экран итогов |
| `scripts/fx.gd` | Частицы, трассеры, вспышки, взрывы, цифры урона |
| `scripts/sfx.gd` | Синтез звуков и музыки |
| `scripts/*.gdshader` | Рельеф, вода, трава, стена шторма |

## Сборка
```bash
godot --headless --import
GODOT_ANDROID_KEYSTORE_RELEASE_PATH=... GODOT_ANDROID_KEYSTORE_RELEASE_USER=... GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=... \
  godot --headless --export-release "Android" build/storm-isle.apk
```
Нужны шаблоны экспорта 4.3, JDK 17 и Android SDK (build-tools 34) — пути задаются в настройках редактора.

Проверка без экрана: `godot --headless -- --autotest` прогоняет целый матч на ускорении и печатает статистику.
